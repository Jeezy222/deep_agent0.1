# 系统功能增强与优化计划

根据您的需求，我们将分三个阶段实施以下核心功能。本计划优先保障前端交互的即时响应（Search/Library）和后台管理的核心能力（Tenant Admin）。

## 1. 前端交互功能 (Frontend - `deep main html`)

### **A. 搜索功能 (`/chat#search`)**
- **目标**：实现点击"搜索"按钮后的交互逻辑。
- **实现**：
    - 创建 `SearchOverlay.tsx` 组件，实现全屏/模态搜索界面。
    - 包含：模糊搜索输入框、历史记录列表（LocalStorage缓存）、加载状态。
    - 修改 `chat.tsx`，绑定侧边栏"搜索"按钮点击事件以显示此组件。

### **B. 库功能 (`/library`)**
- **目标**：实现"库"页面的导航与鉴权。
- **实现**：
    - 创建 `frontend/src/pages/library.tsx` 页面。
    - 实现简单的 Auth Check（检查是否有 Token 或 Credits 数据），未登录跳转回首页。
    - 页面布局包含：Redux 状态持久化（模拟），响应式网格布局展示"库"内容。
    - 修改 `chat.tsx`，绑定侧边栏"库"按钮点击跳转。

## 2. 后台管理系统增强 (Payment Admin - `apps/web` & `apps/server`)

### **A. 租户管理界面升级 (`AdminPage.tsx`)**
- **目标**：从简单的列表升级为功能完备的管理面板。
- **实现**：
    - 添加 **筛选工具栏**：支持按 ID/名称搜索、状态筛选 (Active/Trial)、套餐类型筛选。
    - 添加 **分页控件**：支持上一页/下一页。
    - 优化 **表格展示**：显示更多字段（注册时间、状态标签）。

### **B. 后端 API 扩展 (`payment_controller.py` / `main.py`)**
- **目标**：支持前端的高级查询。
- **实现**：
    - 修改 `/api/v1/debug/orgs` (或新增 `/api/v1/admin/tenants`)。
    - 增加查询参数：`skip`, `limit`, `search`, `status`, `plan`。
    - 实现后端过滤与分页逻辑。

## 3. 资源点计算优化 (Resource Calculation - Backend)

- **目标**：优化计费逻辑公式。
- **实现**：
    - 修改 `apps/server/main.py` 中的 `ai_proxy` 或 `get_current_usage`。
    - 引入新公式：`Cost = Base * Time_Coeff * Plan_Factor`。
    - 增加详细的计算日志输出。

---

**注意**：关于主从数据库架构和 GraphQL 规范，鉴于当前项目架构为 FastAPI + SQLite (REST)，我们将优先在现有架构上实现业务逻辑闭环。数据库迁移和协议重构建议作为后续独立的技术债任务处理。
