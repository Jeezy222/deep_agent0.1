# 积分模块重构与立收通 (LSPay) 支付集成计划

本计划旨在全面升级积分展示模块，并根据提供的 API 文档将支付系统从 Airwallex 迁移至立收通 (LSPay)。

## 1. 积分展示模块重构 (Frontend)

### 1.1 新增组件 `PointsDisplayModule`
- **位置**: `apps/web/src/components/PointsDisplayModule.tsx`
- **功能**:
    - **总积分展示**: 实时显示，精确到小数点后两位。
    - **明细展示**: 按消费、活动、奖励积分分类，支持展开/收起。
    - **可视化**: 使用进度条或环形图展示积分分布。
    - **实时性**: 
        - 初始化时自动加载。
        - 建立 WebSocket 连接监听积分变动。
        - 降级机制：WebSocket 断开时启用 30秒 轮询。
    - **UI/UX**: 响应式设计，加载状态动画，区分明显的配色方案。

### 1.2 集成到 AdminPage
- **位置**: `apps/web/src/pages/AdminPage.tsx`
- **操作**: 定位并替换现有的静态 `td` 单元格，挂载 `<PointsDisplayModule />`。

## 2. 支付系统改造 (Backend)

### 2.1 移除 Airwallex
- **删除**: `apps/server/services/airwallex_payment_service.py`
- **清理**: 移除 `payment_controller.py` 和 `main.py` 中所有 Airwallex 相关代码及路由。
- **配置**: 清理 `.env` 中的 Airwallex 配置。

### 2.2 集成立收通 (LSPay)
- **新增**: `apps/server/services/lspay_service.py`
    - **统一下单 (`tongyixiadan`)**: 实现 API 调用，封装参数（如 `pay_memberid`, `pay_orderid`, `pay_amount`, `pay_notifyurl` 等）。
    - **签名算法 (`jiekouqianmingsuanfa`)**: 实现 MD5 签名逻辑（参数排序 + Key）。
    - **异步通知 (`yibutongzhiguize`)**: 实现回调接口，验证签名并处理订单状态。
    - **订单查询/退款**: 实现查询和退款接口。
- **更新**: `apps/server/controllers/payment_controller.py`
    - `/initiate`: 调用 `lspay_service.create_payment` 获取支付链接或表单。
    - `/callback`: 处理 LSPay 的异步通知，验证签名后更新订单状态。
- **积分联动**: 支付成功回调中触发 `socket_service` 推送积分更新消息。

## 3. 质量保障与测试

- **容错**: 网络超时设置 (5s)，支付接口异常时提供友好提示。
