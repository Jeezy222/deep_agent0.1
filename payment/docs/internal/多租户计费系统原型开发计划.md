# 多租户计费系统全栈原型开发计划

根据您的需求文档和提供的UI截图，我将按以下步骤构建全栈原型。

## 1. 后端开发 (Python/FastAPI)
**目标**：构建符合文档架构的 API 服务，支持 SQLite（原型用）/Postgres 切换。

*   **数据模型 (`models.py`)**：
    *   实现 `User`, `Organization`, `Member`, `Role` (RBAC基础)。
    *   实现 `Plan`, `Subscription`, `UsageRecord` (计费核心)。
    *   *预置数据*：写入截图中的三种套餐（Basic $20, Trial/Standard $40, Pro $200）及其特性列表。
*   **API 接口 (`routers/`)**：
    *   `GET /plans`：返回前端所需的套餐详情、价格、特性图标等。
    *   `POST /orgs` & `GET /orgs/{id}`：组织管理。
    *   `GET /subscription`：查询当前订阅状态与额度。
    *   `GET /usage/current`：返回模拟的 Token 用量数据（支持前端进度条展示）。
    *   `POST /ai/proxy`：模拟 AI 接口网关，记录 Token 消耗（Stub实现）。
    *   `POST /webhooks/paddle`：模拟支付回调处理（幂等性 Stub）。
*   **技术栈**：FastAPI, SQLAlchemy, Pydantic。

## 2. 前端开发 (React/Tailwind)
**目标**：**像素级复刻**您提供的 "Manus Pro" 升级弹窗 UI。

*   **核心组件 (`PricingModal`)**：
    *   **布局**：实现三列卡片布局（Basic, Trial, Pro）。
    *   **交互**：
        *   **月付/年付切换**：顶部 Toggle 开关，联动更新价格（年付省17%逻辑）。
        *   **用量选择器**：中间卡片的下拉菜单（8,000积分/自定义）。
        *   **视觉细节**：中间卡片的高亮边框（蓝色）、"7天免费" 标识、Checkmarks 图标、合规徽章（SOC2, GDPR）。
*   **支付页面**：
    *   构建简易的 Checkout 页面（参考第二张图），展示订单摘要和支付方式（支付宝/银行卡 UI 框架）。
*   **API 集成**：
    *   使用 `fetch` 或 `axios` 对接后端 `/plans` 和 `/subscription` 接口。
    *   实现“升级”按钮点击后的模拟支付流程。
