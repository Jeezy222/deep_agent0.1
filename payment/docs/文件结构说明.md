# 文件结构说明（支付项目）

- `apps/server`：FastAPI 后端源代码与单元测试（保留既有结构）
- `apps/web`：Vite 前端源代码（保留既有结构）
- `docs/`：项目文档与说明
  - `internal/`：IDE/内部过程文档归档（来源于 `.trae/documents`）
- `tests/`：非后端单元测试的脚本归档
  - `integration/`：端到端/集成测试脚本（HTTP 流程、支付联调等）
  - `manual/`：人工验证与示例脚本
- `scripts/`：运维与工具脚本
  - `powershell/`：Windows PowerShell 脚本
  - `windows/`：Windows 批处理脚本
  - `tools/`：通用工具脚本（如端口清理）
- `var/`：运行相关的可变数据
  - `log/`：运行日志与整理日志
  - `data/`：临时数据文件（如 `test.db`）
- `openspec/`：开放设计与方案文档

说明：源代码与配置文件所在目录不参与整理，以保证依赖路径与功能稳定。
