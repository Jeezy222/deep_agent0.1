# 积分模块用户操作手册

## 1. 积分概览
积分是平台使用的核心货币，用于支付 AI 任务、高级功能等。

### 1.1 查看积分
登录后，在管理控制台 (Admin Dashboard) 的租户列表中，可以看到积分展示模块。
- **总积分**: 显示当前账户的可用总积分。
- **积分详情**: 点击积分数字旁的 "详情" 按钮，展开查看积分构成。
  - **基础积分**: 每月/每日自动刷新的积分。
  - **活动积分**: 参与平台活动获得的积分。
  - **奖励积分**: 系统赠送或补偿的积分。

### 1.2 实时更新
- 积分数据会实时更新。当您进行充值或消耗时，无需刷新页面即可看到最新数值。
- 如果网络连接中断，系统会自动尝试重新连接，并在界面上显示状态提示。

## 2. 积分充值 (支付)

### 2.1 发起支付
1. 点击 "升级" 或 "充值" 按钮。
2. 选择套餐或充值金额。
3. 选择支付方式（支持支付宝/微信等，由立收通提供）。
4. 确认订单并跳转至收银台。

### 2.2 完成支付
1. 在收银台完成付款。
2. 支付成功后，页面会自动跳转回系统。
3. 系统收到支付通知后，您的积分余额将立即增加。

## 3. 常见问题

**Q: 支付后积分未到账怎么办？**
A: 通常积分会在 1-5 分钟内到账。如果超过 10 分钟未到账，请联系客服并提供订单号。

**Q: 为什么积分显示 "加载失败"？**
A: 请检查您的网络连接。如果问题持续，请尝试刷新页面。

**Q: 基础积分和奖励积分有什么区别？**
A: 基础积分通常有有效期（如月度清零），奖励积分通常永久有效或有效期较长。系统会优先消耗即将过期的积分。
