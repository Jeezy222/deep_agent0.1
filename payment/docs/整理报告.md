# 文件整理报告（支付项目）

## 本次变更摘要
- 目标：统一文件结构、移除冗余临时文件、保证功能不受影响，并提供自动化整理与撤销能力。
- 自动化：新增 `scripts/organizer.py`，支持 `--dry-run`、`--apply`、`--undo`，生成日志与撤销清单。
- 目录归档：新增 `tests/`、`scripts/`、`var/` 子目录用于测试、脚本与日志数据归档。

## 迁移清单（主要项）
- 测试脚本 → `tests/integration/`
  - `diagnostic_test.py`, `file_test.py`, `test_api_debug.py`, `test_api_debug_v2.py`, `test_checkout.py`, `test_complete_payment_flow.py`, `test_credits.py`, `test_debug.py`, `test_debug_payment.py`, `test_metering.py`, `test_metering_mock.py`, `test_subscription_flow.py`, `test_virtual_checkout.py`
- 人工验证脚本 → `tests/manual/`
  - `manual_test.py`, `simple_test.py`
- 工具与批处理 → `scripts/`
  - `kill_port.py` → `scripts/tools/`
  - `test_alipay.ps1`, `test_alipay_fixed.ps1` → `scripts/powershell/`
  - `run_test.bat`, `run_test_fixed.bat` → `scripts/windows/`
- 日志与数据 → `var/`
  - `integration_error_log.txt`, `test_output.log`, `start_log.txt` → `var/log/`
  - `test.db` → `var/data/`
- IDE 文档 → `docs/internal/`
  - `.trae/documents/*.md` → `docs/internal/`

## 日志与撤销
- 日志：`var/log/organizer.log`
- 撤销清单：`var/log/organizer.undo.json`，可使用 `py scripts/organizer.py --undo` 回滚。

## 对比说明
- 整理前：测试、脚本、日志与数据文件分散在项目根目录，增加维护与查找成本。
- 整理后：按类型归档在专用目录；源代码与配置目录保持不变；依赖路径与核心功能不受影响。

## 核心功能影响评估
- 后端与前端源代码未移动；支付流程、接口与页面均已验证可用。
- 后端集成测试通过：`apps/server/tests/test_payment_integration.py`。

## 建议
- 在 CI 中加入整理助手的干跑检查，防止新增文件放置不规范。
- 为不同环境（dev/test/prod）在日志与数据目录制定保留策略。
